# Code of conduct

Help keep diffle's issue tracker and pull requests useful and welcoming. Be respectful, assume good intent, and discuss the work rather than attacking people. Harassment, threats, discriminatory language, and sharing someone else's private information are not acceptable.

Maintainers may edit or remove content and restrict participation when these expectations are broken. For a public concern, flag the comment or open an issue. For abuse that needs private handling, use [GitHub's abuse report](https://github.com/contact/report-abuse). For a security vulnerability, use [private vulnerability reporting](SECURITY.md).
