# Rename loupe to diffle

"loupe" is too collided to carry a public OSS developer tool: the bare npm name is owned by `chaijs/loupe` (~39M downloads/week), an active direct competitor `eriksaulnier/loupe` ships an agent code-review CLI under the same name, and GNOME's default image viewer is now "Loupe" — so we lose the search terms that matter and cannot own the identifiers a dev tool needs. We rename to **diffle** — a deliberately goofy invented name (`diff` + `-le`) that says exactly what the tool is, carried under a deadpan-serious backronym, the **Deterministic Inspection & Feedback Framework for Language-model Engineering**. Vetting: the bare npm name is free, `diffle.sh` and `diffle.dev` are unregistered, and — the check that actually matters — there is **no developer-tool competitor** named diffle (the collision that ruled out loupe, and later every obvious goofy candidate: `nitpick`, `kibitz`, `peeko`, `snib`, `squinch` all turned out to be existing AI-agent tools; an interim pick "bodkin" was dropped when it turned out to be a Netflix series). Remaining notes: the bare GitHub handle `/diffle` is an active unrelated user, so the org handle is `difflehq`/`usediffle`; a Wordle-style word game shares the name (non-dev, harmless). Before final lock: register `diffle.sh` and run a quick software trademark sweep. All identity strings (package and binary name, MCPB `name`/`display_name`, marketplace slugs, repo, docs domain) funnel through one place so the loupe→diffle swap is a single change.
