# Rename loupe to bodkin

"loupe" is too collided to carry a public OSS developer tool: the bare npm name is owned by `chaijs/loupe` (~39M downloads/week), an active direct competitor `eriksaulnier/loupe` ships an agent code-review CLI under the same name, and GNOME's default image viewer is now "Loupe" — so we lose the search terms that matter and cannot own the npm identifier the JS ecosystem expects. We rename to **bodkin** (a printer's/bookbinder's awl — the fine pointed tool for exact close work on a page, on-thesis with the proof-desk metaphor): the bare npm name is free, the GitHub handle is dormant/usable, `bodkin.sh` looks unregistered, and there is no developer-tool collision. Locking is contingent on confirming `bodkin.sh` at a real registrar and a software trademark sweep for "Bodkin"; the vetted fallback is `quoin`. The migration touches the repo slug, package and binary name, MCPB `name`/`display_name`, the two marketplace manifests, and the docs domain, so all identity strings funnel through one place to make the swap a single change.
