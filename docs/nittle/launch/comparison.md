# nittle and moritzwilksch/diffle, side by side

Draft for Cody. Nothing here has been posted.

Compared: nittle 0.32.0 against moritzwilksch/diffle v0.2.9 (released 2026-10-19). Every moritzwilksch/diffle link is pinned to the v0.2.9 tag, so it keeps working after their default branch moves on. Every row links to code, a PR or docs on one or both repos. Where a row says a feature isn't in their README, it means their v0.2.9 README, and the link goes there so you can check. Absence from a README is not proof the feature is missing. They ship several releases a week, so re-check the "ahead" rows against their latest release the day this goes out.

Repos: [codywilliamson/nittle](https://github.com/codywilliamson/nittle) (formerly codywilliamson/diffle, old links redirect) and [moritzwilksch/diffle](https://github.com/moritzwilksch/diffle).
