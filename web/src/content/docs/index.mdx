  <Card title="Review any comparison" icon="magnifier">
    Working tree, staged, a branch, a commit range, or the whole codebase — rendered in your browser, not the terminal.
  </Card>
  <Card title="Comment inline" icon="pencil">
    Line, range, and file comments with drag-select, threaded replies, and resolve/reopen — saved to durable Review Records.
  </Card>
  <Card title="Close the loop with agents" icon="rocket">
    Return structured feedback over a local MCP server; the agent fixes, replies, and requests re-review.
  </Card>
  <Card title="One self-contained binary" icon="seti:powershell">
    Install with a single command — no checkout, no Node, no sidecar assets. `diffle update` keeps it current.
  </Card>
