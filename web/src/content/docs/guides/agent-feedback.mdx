diffle ships explicit review skills for **Codex** and **Claude Code** that drive a review through a local MCP server. It can also register that server with Cursor, Gemini CLI, VS Code, Windsurf, OpenCode, Zed, and GitHub Copilot CLI. All integrations need the `diffle` command on your `PATH` — see [Installation](/getting-started/installation/).

## Set up your agents

```sh
diffle setup
```

`diffle setup` detects the coding agents you have installed (a binary on `PATH` or a config directory), then shows a checkbox list: `↑↓` move, `space` select, `a` all, `enter` confirm. Detected agents are listed first and pre-checked. It prints a plan of every command it will run and file it will touch, asks `Proceed? [y/N]`, then applies. Re-running is safe; already-configured agents report `unchanged`. Restart the agent or start a new session afterwards.

| agent | id | what setup does |
| --- | --- | --- |
| Claude Code | `claude` | installs the `diffle-review` plugin |
| Codex | `codex` | installs the `diffle-review` plugin |
| Cursor | `cursor` | adds a `diffle` MCP server to `~/.cursor/mcp.json` |
| Gemini CLI | `gemini` | adds it to `~/.gemini/settings.json` |
| VS Code | `vscode` | adds it to the user `mcp.json` |
| Windsurf | `windsurf` | adds it to `~/.codeium/windsurf/mcp_config.json` |
| OpenCode | `opencode` | adds it to `~/.config/opencode/opencode.json` |
| Zed | `zed` | adds it to Zed's `settings.json` |
| GitHub Copilot CLI | `copilot` | adds it to `~/.copilot/mcp-config.json` |

The MCP entry runs `diffle mcp serve` and every other setting in the file is preserved. If a config file isn't plain JSON (comments are common in Zed and VS Code), setup never rewrites it and prints the snippet to paste by hand instead.

To skip the prompts, pass `--agents claude,codex` to select agents and `--yes` to skip the confirmation. Without a terminal and without `--agents`, setup exits 1 with a hint. Undo it with `diffle setup --remove`, which pre-checks every agent diffle is currently set up in. The installer offers to run `diffle setup` when it finishes; set `DIFFLE_NO_SETUP=1` to skip that. See the [CLI reference](/reference/cli/).

## Manual setup

Prefer to install the plugin yourself? Run the commands for your agent.

<Tabs syncKey="agent">
  <TabItem label="Claude Code">
    ```sh
    claude plugin marketplace add codywilliamson/diffle
    claude plugin install diffle-review@diffle-local --scope user
    ```

    Then start a new Claude Code session (or run `/reload-plugins`).
  </TabItem>
  <TabItem label="Codex">
    ```sh
    codex plugin marketplace add codywilliamson/diffle
    codex plugin add diffle-review@diffle-local
    ```

    Then start a new Codex task — existing tasks don't reload newly installed skills/MCP servers.
  </TabItem>
</Tabs>

## The review loop

<Steps>

1. Ask the agent `Review my current changes with diffle.`

2. Leave line/file comments and choose **Return Feedback**.

3. Return to the agent and say `continue`.

4. The agent replies and re-review requests appear in diffle — choose **Refresh diff** from the notice to load new changes.

5. Verify, reply in a thread or resolve, then approve or return more feedback. Asking for more after approval reopens the same review.

</Steps>

![The review panel: a summary field with Return Feedback, Approve, and Cancel, above the unresolved comment thread](/media/summary.png)

The review menu shows the agent's latest update rendered as Markdown. For a long update, select the expand icon in the menu's corner to open the same view in a wide dialog. Your draft summary carries over.

<Aside type="caution">
  If the agent can't start the diffle MCP server, run `diffle --version` in the same shell. If it's missing, fix your `PATH` (re-run the installer) and start a fresh agent session. If you previously installed the `loupe-review` plugin, run `diffle doctor` — it detects the stale plugin and repairs it with `--fix`.
</Aside>

## Running the MCP server directly

The MCP server can also be run directly:

```sh
diffle mcp serve
```

See [MCP tools](/reference/mcp-tools/) for the full tool list.
