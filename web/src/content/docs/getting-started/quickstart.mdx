In this tutorial you review a small change in your browser, leave a comment on one line, and hand that comment to a coding agent as a ready-made prompt. It takes about five minutes and works with any agent you can paste text into.

You need nittle [installed](/getting-started/installation/) and a git repository you can change.

<Steps>

1. Make a change to review.

   Edit any tracked file in the repository, or ask your coding agent to make a small change. Then check git sees it:

   ```sh
   git status --short
   ```

   ```
    M src/greet.ts
   ```

2. Start a review that waits for your feedback.

   From the repository, run:

   ```sh
   nittle --wait > feedback.md
   ```

   The terminal prints the review URL and then waits:

   ```
   [nittle] v0.32.1 — reviewing working tree (1 file changed)
     http://127.0.0.1:47123/?review=8e27d1e1-43ea-419f-8235-1378e5e6606b  (ctrl+c to stop)
   [nittle] waiting for feedback on review 8e27d1e1-43ea-419f-8235-1378e5e6606b (ctrl+c to stop)
   ```

   Your browser opens on the diff: changed files on the left, your edit highlighted on the right. Leave this terminal running.

3. Comment on a line.

   Click the line number of the line you changed. Type a note, for example `Debug log left in, please remove it.`, click the nit tag, and press `Ctrl`+`Enter` (`Cmd`+`Enter` on macOS) to save.

   The comment appears as a card under that line.

   <video src="/media/takes/comment.mp4" poster="/media/takes/comment.jpg" autoplay muted loop playsinline width="1280" height="800" aria-label="Clicking a line number in the nittle diff, typing a comment, tagging it nit and saving it as a card under the line"></video>

4. Send the feedback.

   Click Review in the top bar, then click Return Feedback.

   Back in your terminal, nittle prints one more line and exits:

   ```
   [nittle] review sent back with feedback
   ```

5. Read what your agent will get.

   ```sh
   cat feedback.md
   ```

   ````md
   ## Code Review — working tree — 2026-10-29

   ---

   ### src/greet.ts — Line 2

   ```
       1 | export function greet(name: string) {
     > 2 | +  console.log(name);
       3 |   return `hi ${name}`;
       4 | }
   ```

   **[nit]** Debug log left in, please remove it.

   ---

   ## Summary: 1 comment(s) across 1 file(s)
   ````

   Each comment carries its file, line and a few lines of surrounding code, so the agent doesn't have to guess what you meant.

6. Hand it to your agent.

   Tell your agent:

   ```
   Apply the code review in feedback.md.
   ```

   The agent removes the line you flagged. Run `nittle` again to check its work.

</Steps>

To let the agent start reviews itself, read your comments, reply in threads and ask you to look again, wire it up over MCP with `nittle setup`. That loop is in [Agent feedback](/guides/agent-feedback/).
