# nittle

Local git diff viewer for focused code review. This package installs the prebuilt `nittle` binary for your platform. No Bun runtime is needed; Node only runs the small launcher.

```sh
npx nittle --version
npm i -g nittle
```

Platform binaries ship as optional dependencies (`nittle-linux-x64`, `nittle-darwin-arm64`, `nittle-win32-x64`, and so on). Supported: Linux, macOS and Windows on x64 and arm64.

Docs and the standalone installer: https://nittle.dev
